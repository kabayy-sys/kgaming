# K Gaming XCafe — Senior Product Engineering Instruction
The platform is primarily used on:
- smartphones
- iPads
- cashier tablets

All interfaces must be:
- thumb-friendly
- touch optimized
- responsive
- vertically structured

Avoid desktop-only thinking.

---

# COMPONENT DIRECTION

## Device Cards
Device cards are the heart of the platform.

Cards must:
- be large
- immediately readable
- show clear status
- contain quick actions
- use strong hierarchy

Status must visually dominate the card.

---

# ADMIN EXPERIENCE

Admin/staff workflows must be optimized for speed.

Most actions should require:
- one tap
- or two taps maximum

Avoid excessive modals.
Avoid unnecessary forms.
Avoid deep nested navigation.

---

# PERFORMANCE REQUIREMENTS

The application should feel realtime and lightweight.

Prioritize:
- fast rendering
- optimistic UI
- realtime synchronization
- low interaction friction

---

# DEVELOPMENT STACK

Preferred Stack:
- Next.js
- TypeScript
- Tailwind CSS
- Supabase
- Vercel

Architecture should remain scalable and maintainable.

---

# FINAL EXPECTATION

This project must feel like a real production-grade operational system.

Every implementation decision should reflect:
- operational efficiency
- professional UX thinking
- modern frontend architecture
- premium gaming brand identity
