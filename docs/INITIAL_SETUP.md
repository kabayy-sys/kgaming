# Initial Setup

## Recommended Stack
- Next.js
- TypeScript
- Tailwind CSS
- Supabase
- Vercel

---

# Supabase

Use Supabase for:
- authentication
- realtime database
- activity logs
- booking storage
- device storage

---

# Vercel

Use Vercel for deployment.

Requirements:
- mobile responsive deployment
- realtime updates
- production environment variables

---

# Initial Goal

Version 1 should prioritize:
- realtime device monitoring
- simple booking flow
- operational stability
- mobile-first usability

Avoid unnecessary complexity.
