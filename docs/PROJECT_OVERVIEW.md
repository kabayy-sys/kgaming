## Project Type
Realtime Gaming Device Monitoring & Booking Web App.

This is NOT a complete POS system.

The system focuses on:
- realtime device availability
- customer booking
- shift-friendly operations
- realtime staff monitoring
- operational simplicity

---

# Main Features

## Public Web
- view realtime device availability
- filter devices
- booking flow
- WhatsApp auto message booking
- responsive mobile experience

## Staff Dashboard
- update device status
- approve/reject bookings
- manage devices
- view activity logs
- shift-friendly operational UI

## Owner Dashboard
- full system access
- manage staff accounts
- manage devices
- monitor operational activity
- control system settings

---

# Core Philosophy

The platform must remain:
- simple
- realtime
- fast
- practical
- operationally effective

Avoid feature bloat.

Every feature must solve a real operational problem.
