# Device Information Structure

Each device contains:
- device name
- category
- hourly price
- facilities
- status
- notes
- estimated available time
- last updated by
- updated timestamp

# Device Modification Rules

Staff and owner can:
- create devices
- edit devices
- archive devices

Avoid permanent deletion when possible.

Archive instead of destroying historical data.
