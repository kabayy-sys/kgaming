# Activity Log System

## Purpose
Activity logs are mandatory.

The system uses multiple operational shifts.

Every important action must be recorded automatically.

---

# Logged Activities

## Device Updates
Examples:
- device status changes
- device edits
- maintenance updates

---

## Booking Activity
Examples:
- booking creation
- booking approval
- booking rejection

---

## Account Activity
Examples:
- login
- logout
- password reset
- account creation

---

# Activity Visibility

Staff:
- can view activity logs

Owner:
- full monitoring access

---

# Operational Goal

Logs exist to:
- reduce confusion
- simplify shift transitions
- improve accountability
- track operational history
