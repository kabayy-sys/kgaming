# UI/UX Guidelines
---

# User Experience Rules

## Fast Interaction
- minimize clicks
- avoid complicated forms
- prioritize touch interaction
- maximize readability

---

# Layout Direction

## Public Home
Contains:
- logo/header
- realtime status indicator
- device filters
- responsive device grid

---

# Device Card Rules

Each card should display:
- device name
- category
- status
- availability estimate
- booking button

Status color must dominate visual hierarchy.

---

# Typography

Use modern readable typography.

Avoid:
- tiny text
- overly condensed layouts
- crowded interfaces

---

# Navigation

Mobile-first navigation preferred.

Use:
- bottom navigation
- lightweight hamburger menu
- minimal navigation layers

Avoid enterprise sidebar complexity.

---

# Animation Direction

Animations should feel:
- smooth
- subtle
- premium
- lightweight

Never excessive.

---

# Professional UX Standard

The interface should feel:
- operationally practical
- premium
- modern
- gaming-oriented
- efficient during busy hours
