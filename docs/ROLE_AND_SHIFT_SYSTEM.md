# Role & Shift System

## Roles

### Public
Can:
- view devices
- create booking requests

Cannot:
- edit system
- modify devices
- access dashboard

---

### Staff
Can:
- update device status
- add devices
- edit devices
- archive devices
- approve bookings
- reject bookings
- write shift notes
- view activity logs

---

### Owner
Full access.

Can additionally:
- create staff accounts
- disable staff accounts
- reset passwords
- monitor all operational activity

---

# Shift System

Operational structure:
- morning shift
- night shift

Example accounts:
- pagi01
- malam01

Authentication should remain simple and fast.
